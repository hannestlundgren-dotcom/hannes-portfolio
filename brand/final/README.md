# Lundgren Digital — logopaket

Vald riktning: **Loop**. Symbolen kombinerar L och D i ett öppet flöde. Den vita/gröna punkten markerar dialog, mänsklig kontroll och nästa steg.

## Färger

- Ink: `#171916`
- Lime: `#c7f25a`
- Paper: `#f2f0e9`
- White: `#fbfaf6`
- Deep green: `#536051`

## Rekommenderad användning

- `loop-mark-badge.svg`: profilbild, favicon och liten symbol på valfri bakgrund.
- `loop-mark-light.svg`: fristående symbol på mörk bakgrund.
- `loop-mark-dark.svg`: fristående symbol på ljus bakgrund.
- `loop-lockup-dark.svg`: komplett logotyp på mörk yta.
- `loop-lockup-light.svg`: komplett logotyp på ljus yta.
- `loop-email.svg`: horisontell logotyp anpassad för mejl och dokument.
- PNG-filerna används när SVG inte stöds, exempelvis vissa mejlklienter och sociala tjänster.
- PDF-filen används för utskrift eller delning med tryckeri.

## Grundregler

- Förvräng, rotera eller byt inte färger på symbolen.
- Använd badge-versionen under 80 px. Den fristående Loop-symbolen behöver mer luft.
- Minsta rekommenderade storlek: 28 px för badge, 120 px bred för horisontell logotyp.
- Lämna minst punktens diameter som friyta runt symbolen.
- På mörka ytor används den ljusa versionen. På ljusa ytor används den mörka.

## Mejlsignatur

Den förberedda signaturen förvaras utanför det publika webb-repot tills domänmejlen är aktiv. HTML-signaturen kommer att hämta badge-loggan från `lundgrendigital.se`.

Konceptplanscherna i den överordnade `brand/`-mappen är arbetsmaterial. Filerna i denna mapp är den valda produktionsriktningen.
